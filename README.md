# MITF Website Starter

Starter front-end for the Minya International Theatre Festival (MITF), in Arabic and English.

## Included
- `index.html` — one-page website prototype and section structure
- `styles.css` — responsive visual system (black, burgundy, warm gold)
- `script.js` — Arabic/English toggle, RTL/LTR direction, mobile navigation

## Before publishing
1. Confirm the official domain and repository.
2. Replace placeholder contact details and add official social links.
3. Add approved logos, photographs, credits, and full archive information.
4. Confirm the 2027 dates, slogan, programme, and participation rules before announcing them.
5. Test on mobile and desktop, then publish through the repository's existing deployment workflow.

## Deployment note
This is a static website and can be hosted on many standard web hosts. Do not change DNS, CNAME, or hosting settings until the festival domain and the actual deployment method are confirmed.
